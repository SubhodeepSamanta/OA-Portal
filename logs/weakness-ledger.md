# WEAKNESS LEDGER

The control system. Every failure gets a row. The dominant failure code each week drives what gets taught the next week.

## Failure codes

| Code | Meaning | Medicine |
|---|---|---|
| **M** | Modeling — couldn't strip the story | Statement-stripping drill (rungs 1–3 only, no solving) |
| **C** | Constraint — wrong or unread complexity target | Constraint flashcards; budget before idea |
| **B** | Brute force — couldn't even state it | Always write it; in OAs, code it for partial credit |
| **O** | Observation — had the tools, missed the insight | One-sentence extract → observation bank → D+3 re-derive → identify which unstick move applies |
| **K** | Knowledge — didn't know the algorithm | Derive on the spot → code → 2 variants → 1 at D+7 |
| **I** | Implementation — right idea, wrong code | Write loop invariant as comment first; template library |
| **D** | Debug — knew it broke, couldn't find why | Stress-testing protocol |
| **T** | Time/triage — solvable, spent time badly | Read-all-first; hard time boxes |
